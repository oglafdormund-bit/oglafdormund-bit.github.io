# Шрифт сайта

**Golos Text** — вариативный шрифт, разработанный ParaType для русскоязычных
интерфейсов. Выбран вместо системного стека, чтобы сайт выглядел одинаково
на всех системах: системный шрифт даёт разное начертание на Windows, macOS и
Android, и это самая заметная примета оформления «по умолчанию».

- Источник файлов: Google Fonts (`fonts.gstatic.com`), версия v7.
- Лицензия: SIL Open Font License 1.1, полный текст в `OFL.txt`.
- Подмножества: кириллица и латиница. Расширенные не подключены — на сайте
  не встречаются.
- Один файл на подмножество покрывает начертания 400–700.

**Playfair Display Italic** — курсив с засечками для одного-двух слов в
крупных заголовках.

- Источник файлов: Google Fonts (`fonts.gstatic.com`), версия v40.
- Лицензия: SIL Open Font License 1.1, полный текст в `OFL-playfair-display.txt`.
- Только курсив, начертания 400–600, подмножества кириллица и латиница.

Файлы отдаются с собственного домена. Подключать шрифт ссылкой на Google
Fonts нельзя: это обращение к чужому домену на каждой загрузке страницы.
